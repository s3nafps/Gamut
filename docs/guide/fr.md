# Gamut Repair — Guide de formation

*Imprimez la page de votre poste et affichez-la près du PC. La même aide est dans l'application : menu utilisateur → **Aide**.*

---

## 1. Salle de test (contrôleur qualité)

1. Connectez-vous : **matricule** (ou scannez votre badge) puis **code PIN**.
2. **Scannez le numéro de série** de l'appareil. Le modèle et la couleur s'affichent tout seuls.
   S'ils ne s'affichent pas, choisissez-les dans la liste.
3. Testez l'appareil. Pour chaque contrôle défaillant, appuyez sur **✗**. Pour les mesures
   (ex. courant de fuite), tapez la valeur : elle devient rouge si elle est hors limites.
4. **Tout est bon** → appuyez sur **CONFORME**. L'appareil part.
5. **Problème** → appuyez sur **NON CONFORME** :
   - choisissez le **défaut** dans la liste,
   - ajoutez une **remarque** et des **photos** si utile,
   - appuyez sur **Envoyer en réparation**.
6. Appuyez sur **Imprimer l'étiquette** et collez-la sur l'appareil. Envoyez l'appareil en réparation.
7. Les appareils réparés apparaissent dans **Retours de réparation** (à droite). Scannez-les et
   testez-les **à nouveau**.

**À savoir**
- Un appareil encore en réparation ne peut pas être testé : l'écran l'indique.
- Vous ne pouvez pas valider un appareil que vous avez réparé vous-même.
- Une erreur ? Prévenez votre superviseur. Rien n'est effacé, tout est corrigeable.

---

## 2. Réparation (réparateur)

1. Connectez-vous. En haut, **en rouge** : les appareils **refusés à nouveau** en salle de test.
   Traitez-les en premier.
2. **En attente d'un réparateur** : appuyez sur **Prendre** (ou scannez l'étiquette / le numéro).
3. Lisez le **constat de la salle de test** : défaut, contrôles refusés, remarque, photos.
4. **Panne trouvée** : choisissez la panne réelle → **Enregistrer la panne**.
5. **Qu'avez-vous fait ?** Pour chaque intervention :
   - l'**organe** (ex. pompe de vidange) et l'**intervention** (remplacé, réglé, nettoyé…),
   - les **pièces du stock** utilisées (le stock baisse tout seul),
   - le **temps passé** → **Enregistrer l'intervention**.
6. Pas de pièce ? **En attente de pièces**, puis **Pièces reçues — reprendre**.
7. Fini → **Renvoyer en salle de test**. Seule la salle de test peut valider l'appareil.

---

## 3. Superviseur

- **Réparation** : toutes les réparations en cours ; **Confier à…** pour donner une réparation à
  quelqu'un d'autre. Une **alerte rouge** = appareil refusé trop de fois : décidez (réparer ou rebuter).
- **Rapports** : rendement au 1er passage, défauts (Pareto), temps de réparation, réparateurs,
  contrôleurs. **Exporter vers Excel** ou **Imprimer / PDF**.
- **Pièces** : enregistrez les **réceptions** et les **inventaires** ; surveillez le **stock bas**.
- **Appareils** : cherchez un numéro de série → historique complet, impression, rebut.
- **Journal des modifications** (menu utilisateur) : qui a fait quoi et quand.
- **Tableau de ligne** : le grand écran de la ligne de production.

---

## 4. Administrateur

1. **D'abord** : menu utilisateur → **Changer mon code PIN** (le code 1234 d'origine est refusé ensuite).
2. **Paramètres → Personnel** : ajoutez chaque personne (matricule, nom, rôle, langue, code PIN).
3. **Modèles** et **Couleurs** : ajoutez vos produits avec leur **code dans le numéro de série**.
4. **Numéro de série** : définissez la règle de lecture et testez-la avec un vrai numéro.
5. Vérifiez **Codes défaut**, **Liste de contrôle**, **Organes**, **Interventions**,
   **Pièces de rechange** (avec stock minimum) et leurs traductions.
6. **Textes des écrans** : modifiez n'importe quel mot dans les trois langues.
7. **Général** : objectif de rendement, alerte après N refus, déconnexion automatique.

Rien n'est jamais supprimé : pour ne plus utiliser un élément, décochez **Actif**.
